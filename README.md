
# Quill public beta

Quill is a personal planner for your week: tasks, study, training and the commitments you plan around.

## Download
Current beta: **v2.5.0-beta6** (Android)
- Download the apk from the release page. 
- SHA-256: `19660d9fa2551aab0abf08000c74a2e29555cefe5de66b91e6a190ff3bdd1ec8`
- **This is still beta, use at your own risk**

To install, open the file on your Android phone and allow installs from your browser when asked.

## What this beta includes
- Sign-in with email or Google
- Prep sessions, projects and planning features
- AI requests with a daily limit set by the server (it may change during testing)
- Test ads only, clearly labelled

Subscriptions and paid plans are not part of this beta.
